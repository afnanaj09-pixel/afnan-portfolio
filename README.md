# Afnan Mollah — Portfolio

Personal portfolio of **Afnan Mollah** — writer, editor, AI image creator, and English educator based in Rajbari, Bangladesh.

**Live site:** https://afnanaj09-pixel.github.io/afnan-portfolio/

## About

A single-page portfolio showcasing work across professional writing and editing, proofreading, AI image generation, English tutoring, and data management — presented with a clean, modern dark theme.

## Features

- Responsive single-page layout (desktop, tablet, and mobile)
- Services bento grid with a featured AI banner
- **AI art gallery** — 23 generated images grouped into 7 categories, with filters and a full-size lightbox
- **Video showcase** — 2 AI-generated clips (16:9 landscape and 9:16 vertical) with custom poster frames
- Skills, experience, and education sections
- FAQ accordion and a validated contact form
- Scroll reveal animations, scroll-spy navigation, and a custom cursor

## Sections

Home · Services · Gallery · Videos · Skills · Experience · About · FAQ · Contact

## Tech

Plain **HTML**, **CSS**, and **vanilla JavaScript** — no build step and no dependencies. Hosted on **GitHub Pages**.

## Project structure

```
index.html              # the entire page
css/style.css           # all styles
js/main.js              # gallery builder, filters, lightbox, nav, form
assets/
  Afnan-Mollah-CV.pdf   # downloadable CV
  services-ai.jpg       # services feature image
  gallery/              # 23 AI images + logo.jpeg
  videos/               # 2 AI videos + poster frames
```

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
npx serve .
# or
python -m http.server 8080
```

Then visit http://localhost:8080/.
